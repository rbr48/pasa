Defense Architecture

Enterprise-grade security.
No compromise.

Every module is built for adversarial conditions — thieves, forensic analysts, and coercive situations.

Kinetic Snatch Detection

Continuous accelerometer monitoring (>2.65G). Triggers Device Owner lock, perpetrator selfie, and Telegram alert in under 800ms.

Air-Gap SMS Fallback C2

TOTP-authenticated commands over raw SMS. /locate, /lock, /ring, /wipe — works even with Wi-Fi and mobile data completely disabled.

Zero-Blackout Forensic Camera

CameraX headless capture — no flash, no shutter sound, no screen wake. Front/rear burst, stealth video, and screen recording delivered directly to Telegram.

Fake Shutdown Decoy

Spoofs the OEM power-off animation. Screen goes dark to 0-nit while GPS, mic, and Telegram relay keep running silently behind the screen.

Knox Device Owner Permanence

ADB-provisioned Device Owner. Uninstall disabled at OS level, safe mode blocked, factory reset protection enforced. Survives reboots without reconfiguration.

Hardware Escrow Password Reset

32-byte hardware-backed token enables remote lockscreen PIN reset on Android 14+ without ever having access to the current credential.

Duress PIN & Sterile Decoy OS

Under coercion, enter a special PIN to silently hide banking, crypto, and private apps via Device Owner — leaving a blank, clean decoy environment for the coercer.

GPS + Cell Tower Triangulation

Hardware GNSS streaming every 30 seconds. Fallback to LTE/5G/GSM cell tower triangulation (MCC, MNC, CID, dBm) for indoor localization without satellite fix.

Self-Healing Permission Sovereignty

Permanently locks Camera, Microphone, GPS, SMS, Contacts as "Managed by organization" via Device Owner — unrevokable by the thief or any user action.

SIM Swap Guard

Monitors physical SIM ICCID against a trusted whitelist. Any unauthorized swap triggers automatic lockdown, mugshot capture, and emergency alert.

Hardware USB Data Killswitch

Android 12+ API disables USB data pins (preserving charge only). Neutralizes forensic extraction boxes (Cellebrite, GrayKey) and BadUSB attacks on connection.

Tactile Device Locator

Locate the device silently via custom vibration patterns: intermittent pulse, SOS Morse code (···−−−···), or continuous — without sounding loud sirens.

App Network Isolation Firewall

Blacklist or whitelist packages from network access. Prevents RATs, spyware, or suspect apps from outbound telemetry while PASA itself remains online.

Battery & Drain Monitoring

Alerts on critical battery, abnormal rapid drain (detecting covert surveillance or tethers), and unauthorized charger disconnection in real time.

System-Wide Encrypted DNS

Enforces DNS-over-TLS (Quad9, Cloudflare, AdGuard, or custom) across all networks as Device Owner — defeats ISP snooping and rogue captive portals.

Failed Pattern Guard

Monitors lockscreen failed unlock attempts. At configurable threshold (1–10 tries), triggers silent mugshot capture, hardware lock, and Telegram intrusion alert.

Pocket & Charger Traps

Proximity sensor trap triggers on bag/pocket extraction. Power connection trap auto-kills USB data pins and captures photo when cable is inserted on a locked device.

Direct Outbound SMS & SIM Telemetry

Send SMS directly from the device via Telegram command to identify SIM line numbers. Full dual-SIM carrier, ICCID, network type, and signal telemetry on demand.
